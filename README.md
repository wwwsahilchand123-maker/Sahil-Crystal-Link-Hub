# Sahil Crystal Link Hub

Responsive personal link hub with a black/crimson crystal-glass UI. Plain HTML, CSS and JavaScript; no build tools required.

## Run
Open index.html in a browser.

## Edit links
Edit js/links.js. Change each link's title, description, url and icon. Use an empty url for a disabled placeholder. Copy an object inside a section array to add a card.
